## Stone-Paper-Scissors Game

A simple and interactive **Stone-Paper-Scissors** game built using **HTML, CSS, and JavaScript**. The player competes against the computer, and the winner is decided based on classic game rules.

---

### Features

* 🎮 Play against the computer
* 🔁 Random computer choice generation
* 🧠 Instant result display (Win / Lose / Draw)
* 📊 Live score tracking
* 🎨 Clean and responsive UI

---

### Tech Stack

* **HTML** – Structure of the game
* **CSS** – Styling and layout
* **JavaScript** – Game logic and interactivity

---

### Project Structure

```
Stone-Paper-Scissors/
│── index.html      # Main HTML file
│── style.css       # Styling file
│── app.js          # Game logic
│── rock.png        # Rock image
│── paper.png       # Paper image
│── scissors.png    # Scissors image
│── README.md       # Project documentation
```

---

### How to Play

1. Click on **Rock**, **Paper**, or **Scissors**
2. The computer will randomly choose its move
3. The result will be displayed:
   * 🟢 You Win
   * 🔴 You Lose
   * ⚪ Draw
4. Scores will update automatically

---

### Game Rules

* Rock 🪨 beats Scissors ✂️
* Scissors ✂️ beats Paper 📄
* Paper 📄 beats Rock 🪨

---

### How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Keerthana-webdev/Stone-Paper-Scissors.-.git
   ```
